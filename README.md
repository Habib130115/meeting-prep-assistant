# Meeting Prep Assistant

This repository contains the submission materials for the **Meeting Prep Assistant** assignment.

## Repository Contents

### Prompts
All prompt iterations used during development are stored in the **`prompts/`** folder:

- `prompts/v1.txt`
- `prompts/v2.txt`
- `prompts/v3.txt`

These files show how the prompt evolved across three iterations to improve structure, reliability, and output quality.

### Reflection
The project reflection is included in:

- **`Reflection.md`**
- The accompanying **Word document**

This reflection explains how the prompt evolved, model selection trade-offs, the use of Stitch for UI generation, limitations encountered, and future improvements.
