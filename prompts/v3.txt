STRICT RULES:
- Only use the provided content
- Do NOT hallucinate or invent information
- If information is missing, return "Not specified"
- Ensure clarity, precision, and no repetition

OUTPUT MUST BE STRICT JSON FORMAT:

{
  "summary": "...",
  "risks": [
    {
      "description": "...",
      "impact": "High | Medium | Low"
    }
  ],
  "talking_points": [
    "..."
  ],
  "next_steps": [
    {
      "action": "...",
      "owner": "..."
    }
  ],
  "cover_image_prompt": "..."
}

- summary:
  Provide a concise and clear overview of the meeting

- risks:
  Identify specific risks from the content
  Assign impact level (High, Medium, Low)

- talking_points:
  Stakeholder-ready points (max 15 words each)

- next_steps:
  Must be actionable and clearly defined
  Include an owner if possible, otherwise "Not specified"

- cover_image_prompt:
  Describe a professional image representing the meeting context

Ensure the output is clean, structured, and professional.
